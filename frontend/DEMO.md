# SpotScore 데모 시나리오

4주차 데모용 시연 순서. CLAUDE.md 대시보드 화면 구성(업종 선택 → 랭킹+지도 → 상세 패널) 흐름을 그대로 따른다.

## 사전 준비

- 백엔드(`:8080`) 기동 + 배치 1회 이상 실행 완료(`POST /api/v1/admin/batch/run`)
- 좌표 시딩 완료(`POST /api/v1/admin/regions/seed-coordinates`) — 안 되어 있어도 앱은 정상 동작하지만 지도에 마커가 안 뜸
- 프론트는 `http://localhost:5173`에서 실행 (Kakao Map JS 키가 이 도메인으로 제한되어 있어 다른 포트에서는 지도가 안 뜸)

## 시연 순서 (약 3분)

1. **업종 선택** — "식료품 소매" 선택. 업종 선택 전에는 랭킹/지도/상세 패널 모두 "먼저 선택해주세요" 안내만 뜨는 것부터 짚고 시작(필수 선택 흐름 강조).
2. **랭킹 확인** — 왼쪽 랭킹 리스트에 지역이 점수 내림차순으로 뜨는 것 확인. 1위 지역 점수가 왜 높은지는 아직 말하지 않고 다음 단계로 넘어감(궁금증 유발).
3. **지도 확인** — 오른쪽 지도에 랭킹과 동일한 지역 마커가 찍혀 있는 것 확인. 랭킹 리스트에서 지역을 클릭하면 지도가 해당 마커로 이동하고, 반대로 지도 마커를 클릭하면 랭킹 리스트에서 해당 행이 하이라이트되는 양방향 연동을 직접 클릭해서 보여줌.
4. **"왜 이 점수인가" 설명 (상세 패널)** — 1위 지역을 클릭해 상세 패널을 연다.
   - 종합 점수를 크게 보여주고, 바로 아래 브레이크다운 3개(①인구 규모 ②가구 구조 ③경쟁 밀집도) 막대그래프로 시선을 옮긴다.
   - 각 브레이크다운 카드의 원자료 값(총인구, 가구 수, 동일 업종 업소 수 등)을 짚으며 "이 지역이 왜 이 점수를 받았는지"를 원자료 기준으로 설명 — 예: "경쟁 밀집도 점수가 낮은 건 동일 업종 업소 수가 많기 때문"처럼 점수와 원자료를 연결해서 말한다.
   - 순위가 낮은 지역도 하나 클릭해서 브레이크다운이 반대로 나오는 것(예: 인구 규모는 높은데 경쟁 밀집도가 낮아 종합 점수가 밀린 경우)을 대비시켜 보여주면 "종합 점수 하나만 보지 않고 브레이크다운을 봐야 하는 이유"가 자연스럽게 전달된다.
5. **엣지 케이스 짚기 (선택)** — 시간이 남으면:
   - 아직 배치가 안 돈 업종을 선택해 "아직 집계된 데이터가 없습니다" 문구가 뜨는 것을 보여주고, 이게 "0점"이 아니라 "데이터 자체가 없음"이라는 걸 구분해서 설명.
   - 원자료 일부가 없는 지역이 있다면 브레이크다운 카드에 "N/A"가 뜨는 것도 같은 맥락에서 짚어줄 수 있음(SGIS 통계값 5 이하 비공개 케이스).

## 알아두면 좋은 제약 (질문 대비)

- 좌표가 시딩되지 않은 지역은 지도에 마커가 안 뜨지만, 랭킹 리스트·상세 패널은 정상 동작한다(좌표는 지도 표시 전용 부가 정보).
- 현재 배치는 강남구 역삼1동/역삼2동 2개 행정동만 대상으로 설정되어 있다(`SPOTSCORE_BATCH_TARGET_REGIONS`) — "서울 전체"가 아니라 파일럿 범위. 백엔드 구조 자체는 전국 확장이 가능하도록 설계돼 있고, 대상 지역 확장은 설정값 변경만으로 가능하다는 점을 강조하면 좋음.
- 가중치(인구 규모/가구 구조/경쟁 밀집도 비중)는 `ScoreWeightConfig` 테이블 값으로, 코드 수정 없이 조정 가능하다.
